# 🔐 Password Generator

This is a Python program that generates strong and random passwords.

## 🚀 Features
- User-defined password length
- Multiple complexity levels (Low, Medium, High)
- Random password generation

## ▶️ How to Run
python password.py

## 📌 Example
Enter length: 8  
Choice: 3  
Output: A@9kLp#2
